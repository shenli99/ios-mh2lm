# C5：频率控制、本地电源域与 corner 协调

[返回总计划](../CLOCK-SYSTEM-IMPLEMENTATION-PLAN.md)。各卡默认遵守[总计划 3.5 共享约束](../CLOCK-SYSTEM-IMPLEMENTATION-PLAN.md#35-所有卡共享的默认约束)，卡内只写特有边界。状态：未开始。

## 阶段目标与退出条件

各硬件类型先做一个已证样本；本地电源域与远端供电票分别验收。divider／RCG／PLL 可以在已确认且被保留的足够供电下单独验证；不能以电源占位成功作为前置。主动变频需要实际拥有的时钟、可停止消费者及适当的完成证据。

### C5-01 发布一个本地电源域的只读资源接口

- **目标**：通过公共电源域句柄描述并查询一个本地 GDSC。
- **前置**：C1-04；所属 CC 已初始化；补齐该域样本卡及域外访问通路。
- **需求与边界**：域操作仍调用唯一 CC 寄存器 owner；只发布归属、父依赖、支持能力和可合法读取的状态。域关闭时禁止为了查询访问域内寄存器，不建立第二个 MMIO writer。
- **本地检验**：缺访问时钟／供电时返回不可读；多域归属与 inherited 状态；未知供电不标 On。
- **实机检验**：在有效访问凭据下取得指定域的状态／来源；不可访问条件通过无写诊断拒绝。
- **预期结果**：电源层能引用该域，尚无 power-on/off 能力。
- **失败归属**：C5-01 ownership／access／state-decode。

### C5-02 打开一个获准的本地 GDSC

- **目标**：按已核实流程把一个由驱动接管、原本关闭的域变为可用。
- **前置**：C5-01；真实供电／corner、域外访问时钟及必需 reset／隔离条件已由已验接口建立。
- **需求与边界**：只一种 GDSC 变体、一个域；保留 HW_CONTROL／override 等边界。不改该域 PLL／RCG，不实现自动掉电。
- **本地检验**：已知时序、PWR_ON 等该类型完成条件、超时及部分上电保留；依赖不全不得写。
- **实机检验**：从明确关闭状态执行 on，记录实际控制写和域就绪，再执行允许的只读访问。若只能观察继承 On，不能判此卡通过。
- **预期结果**：该域主动上电可用；供电电压物理值仍另列证据。
- **失败归属**：C5-02 dependency／control／power-on-wait；缺冷态样本则受阻。

### C5-03 关闭自己取得的本地 GDSC

- **目标**：在全部使用者停止后关闭一个由驱动拥有的域。
- **前置**：C5-02；该域的 DMA／IRQ／clock／reset／隔离退出合同均已明确并可执行。
- **需求与边界**：只该域的关闭；有共享者、继承保护或状态未知时拒绝。最后一个 clock 引用消失不直接授权掉电；不顺带降低共享供电票。
- **本地检验**：未停止 DMA／仍有域引用时拒绝；类型特定顺序、超时保留；掉电后禁止域内读写。
- **实机检验**：记录本域使用者退出证据后执行 off，观察该类型关断状态；用 C5-02 恢复到允许状态。共享 rail 未掉电不作为失败。
- **预期结果**：该 GDSC 的关断合同闭合，不能推广为整条供电 rail-off。
- **失败归属**：C5-03 quiesce／isolate／power-off-wait。

### C5-04 修改一个固定父源的 divider

- **目标**：让一个独占样本在两个合法整数分频值间切换。
- **前置**：所属 CC 门控已验；divider 样本卡、停止条件、父源及足够且被保留的供电已确认。
- **需求与边界**：只一个 divider 编码类型，父源和 PLL 不变；先用停止后修改方式，不声称 glitchless。新增 setRate 能力仅覆盖该样本允许范围。
- **本地检验**：编码／rounding、非法范围、共享者拒绝；读回必须由实际字段重算，不能只回显请求值。
- **实机检验**：停用样本、设置分频、按已验路径开启，记录实际字段及派生频率；有独立频率测量时附测量，否则只证明配置和运行条件。
- **预期结果**：该 divider 的受控频率配置可用。
- **失败归属**：C5-04 rate-selection／divider-write／recalc。

### C5-05 配置一个整数模式 RCG

- **目标**：通过一个已知 RCG 在合法固定父源／整数分频配置间切换。
- **前置**：RCG 样本卡、父源已验且被持有；门控与供电／停止凭据具备。
- **需求与边界**：只一个 RCG 变体的整数模式，保留更新握手和必要 safe 配置；不改父 PLL，不加入 M/N/D 分数模式。
- **本地检验**：parent-map、配置掩码、update 顺序／超时；非法 parent 拒绝；请求约束可满足才写。
- **实机检验**：单资源执行一次配置转换，记录 CMD／CFG 与 update 完成，重新解码父源和频率；使用者可恢复运行。
- **预期结果**：一个 RCG 整数模式可用，更新握手有独立证据。
- **失败归属**：C5-05 parent-map／program／update-wait。

### C5-06 为同类 RCG 增加分数模式

- **目标**：正确配置一个已证合法的 M/N/D 分数频率。
- **前置**：C5-05；该分数模式和位宽已核实，安全样本供电满足要求。
- **需求与边界**：只该 RCG 类型的一组分数配置；不同时增加另一 RCG 变体或 PLL 改频。
- **本地检验**：M/N/D 编码、符号／反码和整数计算溢出、模式转换及 update 失败；独立参考计算频率。
- **实机检验**：实际字段／模式与指定合法配置一致，update 完成且样本运行；可用计量手段单独验证实际频率。
- **预期结果**：分数模式独立于整数模式验收，不能靠整数样本通过代替。
- **失败归属**：C5-06 fraction-encode／mode／update-wait。

### C5-07 启动一个已配置但未运行的 PLL

- **目标**：按一种 PLL 变体的既定配置启动并建立输出。
- **前置**：PLL 样本卡、真实供电及访问条件成立；PLL 原本停止且无未知使用者。
- **需求与边界**：只一种 PLL、一个已验证配置；不修改 L／alpha 等频率参数，不接管 live／FSM 状态。
- **本地检验**：mode／opmode／lock／output 顺序、各等待超时，部分启动不能被记为已关闭或可释放。
- **实机检验**：从已确认停止态进入 lock 和允许输出态，记录实际完成条件；其下游用已验路径验证可运行。lock 不单独证明输出频率准确。
- **预期结果**：该 PLL 既定配置的主动启动成立。
- **失败归属**：C5-07 admission／start／lock／output。

### C5-08 停止自己拥有且无使用者的 PLL

- **目标**：在全部下游释放后关闭一个已由 C5-07 启动的 PLL。
- **前置**：C5-07；全部子源、门控及其他 master 的所有权明确。
- **需求与边界**：只该 PLL 的停止；下游仍选择或仍运行时拒绝，不借机重配共享 GPLL。
- **本地检验**：子引用／未知 owner 拒绝、停止顺序及期限、超时后保持不确定账本。
- **实机检验**：取得下游退出证据后执行 stop，确认该类型输出／运行条件消失；再用 C5-07 恢复。
- **预期结果**：该 PLL 的启停可闭合，未支持共享运行中改频。
- **失败归属**：C5-08 children／disable-output／stop-wait。

### C5-09 离线修改一个 PLL 的频率配置

- **目标**：在 PLL 停止时配置第二个已核实的合法频率。
- **前置**：C5-07／08；新频率参数及电源要求已确认并满足。
- **需求与边界**：只同一种 PLL 的离线配置；使用已验启停；不改变 live PLL，不猜参数表。
- **本地检验**：参数表、L／alpha 等字段边界、频率计算、配置失败保留状态；旧配置不会被当成新频率成功。
- **实机检验**：stop→配置字段→start／lock→下游运行，记录实际字段重算结果；无独立计量时只验配置／锁定合同。
- **预期结果**：一个新离线频点可用；live retune capability 继续关闭。
- **失败归属**：C5-09 rate-table／program／new-config-check；启停既有错误保留对应 phase。

### C5-10 拒绝不相容的共享频率约束

- **目标**：两个使用者提出不相容约束时，在改硬件前给出确定拒绝。
- **前置**：C1-05 公共账本合同本地通过、一个已验 setRate 后端；不要求先取得普通 GCC gate 的实机样本。
- **需求与边界**：定义并实现 min／max／exact 的一个公共仲裁合同；本卡只新增冲突处理，合法单消费者配置仍走已验实现。共享 parent 的隐式改频未经授权时同样拒绝。
- **本地检验**：可满足区间、冲突 exact、上下限冲突、撤回后重新可满足；拒绝保持旧票／旧配置。
- **实机检验**：两个诊断消费者发冲突请求，第二个无任何硬件写且原时钟继续；撤回冲突方后合法请求可完成。
- **预期结果**：共享 setRate 不采用最后写入者覆盖策略。
- **失败归属**：C5-10 constraints／arbitration／no-write-rejection。

### C5-11 协调一次 corner 提升后的升频

- **目标**：一个已验频点转换必须等真实供电／corner 提升完成后才执行升频。
- **前置**：C4-08 或等价已验电源接口、所需本地 setRate 卡、C5-10；资源有准确 rate-to-corner 表。
- **需求与边界**：仅一个 consumer／两个频点的 upward 转换；使用异步依赖，不跨 provider 持锁等待；没有电源能力时请求必须拒绝。
- **本地检验**：供电失败／Pending 时无升频，完成顺序正确；升频失败后不擅自降回不确定供电。
- **实机检验**：同一请求记录 power token 的完成早于 clock write，随后频点完成；单独保留回归。
- **预期结果**：一次升频的时序得到证明；不声称已完成自动 DVFS 策略。
- **失败归属**：C5-11 power-request／power-wait／clock-apply。

### C5-12 协调一次降频后的 corner 降低

- **目标**：只有本地降频及依赖要求确认后才降低该消费者的 corner 票。
- **前置**：C5-11；低频点及共享电源聚合要求均可核实。
- **需求与边界**：只 downward 转换；其他使用者需要高 corner 时保留聚合需求。时钟状态不确定时不降供电，不把撤票等同物理降压。
- **本地检验**：clock 失败／Pending 禁止降低票、另一个用户仍需高 corner、降票失败保持已知频率和不确定票状态。
- **实机检验**：记录 clock 完成早于降低票；本方低票与电源聚合结果分开，硬件实际电压无测量时不推断。
- **预期结果**：一次降频／降票合同闭合，供电与时钟失败可分辨。
- **失败归属**：C5-12 clock-lower／shared-requirement／corner-lower。
