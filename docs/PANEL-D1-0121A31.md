## 本次实测

先在一个终端保持 USB 日志接收：

```sh
sudo SWEET_ACM_DEVICE=/dev/ttyACM0 /home/shenli/work1/ref/ios-mh2lm/tools/sweet-usbacm-log.sh /home/shenli/work1/logs/live-0121a31-abi608-panel-retained.txt
```

手机进入 fastboot 后，在另一个终端临时启动：

```sh
fastboot boot /home/shenli/work1/out-bs/boot-16k-0121a31-abi608-panel-retained.img
```

进入桌面、确认画面更新后，按一次息屏键，等约 5 秒，再按一次唤醒。
无论是否点亮，继续接收至少 30 秒，再 Ctrl+C 停止；记录画面和触控表现。
本次只测 retained 的一次 OFF/ON；无需再编同一内核或重测 a30，不展开其他档位。

日志检查顺序：

`初次 HANDOFF active → OFF 命令完成 → reset low/ULPS entry/link 停/撤票 ACK →
OFF complete 且不再 consumer cancelled → ON begin → 供电 ACK/ULPS reentry/PLL/exit →
host soft reset → DDIC reset/ON 命令 → owned source/flush → fresh pixels → touch/ON complete`。

GPIO 配置差异继续作为诊断；commanded 电平不等于物理电压，撤销本票不证明物理断电。
若 USB 缺关键记录，再补持久日志。
