```text

     ULPS entry lane-status=0
     ULPS entered after HS stop; ESC0 halt pending
     ESC0 halted after ULPS; PHY shutdown next
     原PHY/DATA/panel票停放 → OFF complete
ON ：ESC0 running before ULPS host setup
     原host/PHY配置、ULPS重入/退出
```
